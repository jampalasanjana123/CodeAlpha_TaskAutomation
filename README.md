
# CodeAlpha Task Automation with Python

## Project Description
This project automates the task of moving JPG and JPEG
images from a source folder to a destination folder.

## Features
- Automatically identifies JPG and JPEG images
- Creates folders automatically
- Moves images using Python
- Prevents overwriting files with the same name
- Displays the number of images moved

## Technologies Used
- Python 3
- os module
- shutil module
- File handling

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Place images in the source_images folder.
4. Run:

   python jpg_mover.py

5. Check the jpg_images folder for moved images.

## Expected Output
The program displays the names of moved images
and the total number of images moved.
